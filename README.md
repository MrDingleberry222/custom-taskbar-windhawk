# Custom Taskbar (Windhawk)

A Windows 10 taskbar customization mod powered by Windhawk.

## Features

- Customize taskbar icon position
- Center taskbar icons
- Adjust icon offsets
- More customization coming soon

## Installation

1. Install Windhawk
2. Open Windhawk
3. Create a new mod
4. Paste the code from `mod.cpp`
5. Compile and enable

## Supported Systems

- Windows 10
